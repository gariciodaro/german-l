# Woche 4 – Wohnen
Themen: Wohnung beschreiben, Möbel, Mietanzeige.

## Grammatikziele
1. Adjektivendungen im Singular (Nom./Akk.) mit bestimmten & unbestimmten Artikeln (nur häufige Formen)
2. es gibt + Akkusativ
3. Präpositionen: in, über, unter, neben, vor, hinter (Wiederholung – Lagebeschreibung)
4. Haben / Es hat (Merkmale)

### 1. Adjektivendungen (Fokus A2-Auswahl)
Bestimmter Artikel:
- Nominativ: der kleine Balkon, die neue Küche, das große Zimmer
- Akkusativ: den kleinen Balkon, die neue Küche, das große Zimmer
Unbestimmter Artikel:
- Nominativ: ein kleines Zimmer, eine neue Küche, ein großer Balkon
- Akkusativ: ein kleines Zimmer, eine neue Küche, einen großen Balkon
Merktipp: Maskulin Akkusativ -en.

### 2. es gibt + Akkusativ
- Es gibt einen Balkon.
- Es gibt eine Garage.
Negativ: Es gibt keinen Aufzug.

### 3. Lage
- Das Sofa steht im Wohnzimmer.
- Der Tisch steht vor dem Fenster.
- Das Bett ist neben der Lampe.
Fragen: Wo steht ...? / Gibt es ...?

### 4. Wortschatz (Auswahl)
Räume: das Wohnzimmer, das Schlafzimmer, die Küche, das Bad, der Flur, der Balkon, der Garten
Möbel: das Bett, der Tisch, der Stuhl, das Sofa, der Schrank, die Lampe, der Teppich
Eigenschaften: hell, groß, klein, ruhig, modern, möbliert, teuer, billig

## Funktionale Sprache
- Die Wohnung hat ...
- Sie ist (hell und ruhig).
- Die Miete ist ... Euro.
- Warmmiete / Kaltmiete
- inklusive / ohne

## Typische Fehler
- *Es gibt ein Balkon* → einen Balkon.
- *Die Wohnung hat ein groß Balkon* → einen großen Balkon.
- Falsche Reihenfolge: groß hell Zimmer → ein großes helles Zimmer (A2: 1–2 Adjektive okay)

## Strategie
1. Fotos beschreiben (3 Sätze → erweitern).
2. Adjektive sammeln und clustern (positiv / negativ).
3. Eigene Wohnsituation in Stichpunkten → Text.
