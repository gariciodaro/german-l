# Woche 4 – Übungen Wohnen

## A. Warm-up
Beschreibe dein Zimmer in 3 Sätzen.

## B. Adjektivendungen einsetzen
1. Die Wohnung hat (ein / groß / Balkon).
2. Ich suche (eine / ruhig / Wohnung).
3. Es gibt (ein / modern / Bad).
4. Wir haben (einen / hell / Flur).
5. Ich mag (das / klein / Zimmer) nicht.

Lösungen: 1. einen großen Balkon 2. eine ruhige Wohnung 3. ein modernes Bad 4. einen hellen Flur 5. das kleine Zimmer

## C. es gibt / keinen
Formuliere negativ.
1. Es gibt einen Balkon. → ...
2. Es gibt eine Garage. → ...
3. Es gibt ein Fenster im Bad. → ...
Lösungen: Es gibt keinen Balkon / keine Garage / kein Fenster...

## D. Möbel zuordnen
Ordne: schlafen – kochen – sitzen – essen – lesen.
Bett / Herd / Stuhl / Tisch / Lampe
Muster: schlafen – Bett, kochen – Herd, sitzen – Stuhl, essen – Tisch, lesen – Lampe (Licht)

## E. Fotos beschreiben (Beispielanweisung)
Bild A: hell / modern / Sofa / großer Tisch.
Antwortmodell: Das Wohnzimmer ist hell und modern. Es gibt ein graues Sofa und einen großen Tisch.

## F. Fehlersuche
1. Es gibt ein großen Balkon.
2. Ich habe eine modern Küche.
3. Die Wohnung ist ruhig und helles.
4. Ich suche ein billige Zimmer.
5. Das ist ein teuer Miete.
Lösungen: 1. einen großen 2. moderne Küche 3. ruhig und hell 4. ein billiges Zimmer 5. eine teure Miete.

## G. Schreibaufgabe
Mietanzeige: 6–7 Sätze (Lage, Größe, 3 Möbel, Miete, Kontakt).

## H. Partnerarbeit
Frage: Was ist dir wichtig? (ruhig, Balkon, Preis...)
Antworten vergleichen.
