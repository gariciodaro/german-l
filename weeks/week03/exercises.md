# Woche 3 – Übungen Stadt & Orientierung

## A. Warm-up
Nenne 5 Orte in deiner Stadt.

## B. Wo oder Wohin?
Fülle ein: in / auf + richtigen Artikel.
1. Ich gehe ____ (Markt).
2. Wir sind ____ (Marktplatz).
3. Er fährt ____ (Bahnhof).
4. Sie steht ____ (Haltestelle).
5. Ich treffe dich ____ (Kirche).

Lösungen: 1. auf den Markt 2. auf dem Marktplatz 3. zum Bahnhof (alternative: in den Bahnhof – Kontext) 4. an der Haltestelle 5. vor der Kirche (akzeptiere in der Kirche je nach Kontext)

## C. Imperativ bilden
1. (du) geradeaus gehen → ...
2. (Sie) links abbiegen → ...
3. (ihr) hier warten → ...
4. (Sie) nicht rauchen → ...
Lösungen: Geh geradeaus! / Gehen Sie links ab! / Wartet hier! / Rauchen Sie nicht!

## D. Sätze ordnen
(a) dann / rechts / Sie / biegen
(b) gehen / geradeaus / 200 Meter / Sie
(c) sehen / links / Apotheke / die / Sie
Lösung: Gehen Sie 200 Meter geradeaus, dann biegen Sie rechts, links sehen Sie die Apotheke. (Feinschliff: ... rechts ab. Links sehen Sie ...)

## E. Mini-Routen
Beschreibe den Weg:
Start: Bahnhof → Ziel: Museum (3 Schritte). Nutze: geradeaus, links, rechts, an der Ampel.

Beispiel: Gehen Sie vom Bahnhof geradeaus bis zur Ampel. Dann rechts. Das Museum ist links neben der Kirche.

## F. Fehler finden
1. Geh Sie geradeaus.
2. Es ist in den Platz.
3. Fahren wir in der Stadtzentrum.
4. Du geht links.
5. Ich gehe zu die Bank.
Lösungen: 1. Gehen Sie... 2. auf dem Platz 3. ins Stadtzentrum 4. Du gehst... 5. zur Bank.

## G. Partnerarbeit (Info-Gap)
Schüler A hat einen Stadtplan ohne Apotheke + Rathaus.
Schüler B ohne Museum + Bank.
Fragen: Wo ist die Apotheke? / Wie komme ich zur Bank?

## H. Schreibaufgabe
Beschreibe eine Route von deiner Wohnung zu einem Ort (6 Sätze).
